## Добро пожаловать в мой блог

Это первая статья на русском языке. Многоязычные функции настроены:

- **中文** (zh) — Язык по умолчанию
- **English** (en)
- **日本語** (ja)
- **Русский** (ru)

### Проверка функций

1. Выпадающий список смены языка
2. Автоматический редирект с префиксом URL
3. Фильтрация контента по локали

> Технологии: Astro 6 + Tailwind CSS + i18n
