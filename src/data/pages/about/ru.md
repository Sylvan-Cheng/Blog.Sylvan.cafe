## Обо мне

Привет, я Sylvan.

Это личный блог, созданный с помощью Astro и Tailwind CSS, с поддержкой четырёх языков: китайского, английского, японского и русского.

### Технологии

- **Фреймворк**: Astro 6
- **Стили**: Tailwind CSS 4
- **Шрифты**: Noto Sans / SC / JP + Fira Code
- **Комментарии**: Giscus
- **Поиск**: Pagefind
