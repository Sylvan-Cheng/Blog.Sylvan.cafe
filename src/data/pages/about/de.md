## Über mich

Hallo, ich bin Sylvan.

Dies ist ein persönlicher Blog, erstellt mit Astro und Tailwind CSS, der fünf Sprachen unterstützt: Chinesisch, Englisch, Japanisch, Russisch und Deutsch.

### Tech-Stack

- **Framework**: Astro 6
- **Styling**: Tailwind CSS 4
- **Schriftarten**: Noto Sans / SC / JP + Fira Code
- **Kommentare**: Giscus
- **Suche**: Pagefind
