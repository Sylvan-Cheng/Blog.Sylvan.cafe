## About Me

Hi, I'm Sylvan.

This is a personal blog built with Astro and Tailwind CSS, supporting four languages: Chinese, English, Japanese, and Russian.

### Tech Stack

- **Framework**: Astro 6
- **Styling**: Tailwind CSS 4
- **Fonts**: Noto Sans / SC / JP + Fira Code
- **Comments**: Giscus
- **Search**: Pagefind
